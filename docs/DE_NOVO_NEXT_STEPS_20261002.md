# CASMI class 3 与真正分子生成：下一步

日期：2026-10-02。本文审查冻结源码 `a45c65e9f16501c554dfd4a12679003d630cb0ff`，不修改正在运行的训练。写作时正式 Kaggle v2 已启动 GPU 训练，尚无完成结果和新公榜分数；实际状态以 [运行记录](../kaggle_release_gan/status.json) 为准。既有实验的验收边界见 [GAN 结果解读](GAN_RESULT_INTERPRETATION_20261002.md)。

**用户希望从谱图生成正确的新分子。本轮完成了真实条件指纹 GAN 和有限图编辑候选机制，仍缺少可训练的 SMILES／分子图解码器。** 下一步应补齐解码器与分子式推断，再验证对抗损失是否增加准确结构召回。

## class 3 为什么需要独立生成分支

官方数据说明将 class 3 定义为 PubChem 中不存在的结构。本赛分子质量跨度为 157–1159 Da，不能把小分子或单一离子模式的生成结果直接外推到整个赛题。[比赛数据说明](https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/data)

如果真结构不在实际候选池，纯候选排序的精确召回上限就是零。扩大公共库可以补充部分缺失候选，但对确实未收录的结构，仍需建立新连接关系。必须区分“没有参考谱”“本地库缺失”和“PubChem 本身不存在”：本轮 unknown 验收主要模拟前两种情况，不能自行改称 class 3 验收。

## 本轮机制实际能做什么

| 机制 | 已实现能力 | 尚不能支持的结论 |
|---|---|---|
| 条件指纹 GAN | 谱图条件下交替训练 G/D，输出 2048 位 Morgan 指纹概率；用指纹相似度参与候选排序 | 指纹不是唯一分子身份，没有指纹到结构的学习解码器 |
| 同分子式图编辑 | 从最多两个质量相容锚点，各尝试最多 256 次，最多补充 32 个合法新候选／题 | 不是 GAN 直接生成图，也不是任意骨架或官能团生成 |
| 诊断离子／中性丢失先验 | 提供候选官能团支持与软排名信息 | 不等于完整碎裂模型；常见丢失也不专属于一个官能团 |

[图编辑实现](../casmi_ml/graph_candidates.py) 每次从**原始锚点**选两条非芳香单键，交换四个不同端点；没有递归累积编辑。编辑阶段保留原子与电荷、每个原子的度和键阶和，并校验连通性、合法价态、完整分子式及精确质量。芳香键及多重键不会由该操作直接重建；最终再按互变异构体身份归一化。

这能产生部分不同连接异构体，有时也能改变环连接，但可达空间仍受锚点的元素组成和连接模式限制。正确分子式不在锚点中，或真图无法通过一次这类交换得到时，增加尝试次数也无效；没有合适锚点时没有生成入口。合法、同质量只是必要条件，不能证明分子解释了谱图。

当前保护阈值为 0.75，高置信查询不生成图。监督指纹与 GAN 两臂共享新增图池，因此双方差异可以检验对抗学习的排序作用；不能解释为 GAN 多生成了分子。图的“新颖”仅指不在本题传入的候选身份集合，未检索整个 PubChem。实际新增真结构覆盖与逐题 SMILES 必须从完成后的报告核实。

## 最小可执行路线：补上条件 SMILES 解码器

MSNovelist 已展示“谱图预测指纹＋分子式 → SMILES”的两阶段路线，结构解码器可以利用没有谱图的公共结构预训练，并模拟预测指纹误差。其原版输入是 3609 维 CSI:FingerID 指纹，与我们的 2048 位 Morgan 不同，不能直接接旧检查点。[原论文](https://www.nature.com/articles/s41592-022-01486-3)、[作者代码](https://github.com/meowcat/MSNovelist)

建议首轮实现三个接口，先形成无 GAN 的监督生成基线：

1. `predict_formula_candidates(group) -> [(formula, probability)]`：由前体、加合物和可用谱峰推断前 5 个分子式，避免借用检索锚点作为唯一答案。只有数据确实提供同位素信息时才使用同位素证据。元素范围、质量误差、价态和 DBE 校验需明确；诊断离子与丢失用于软支持。
2. `decode_structures(fp_probabilities, formula, seed, budget) -> SMILES`：训练小型条件 Transformer 或 LSTM，以元素剩余计数辅助生成；交叉熵训练，公共结构提供自计算指纹与规范化目标。先测试真实指纹＋真实分子式的重建上限，再输入训练内交叉验证得到的预测指纹；用这些误差校准输入扰动，避免只在完美指纹上训练。
3. `validate_and_rank(group, generated, library_candidates) -> top25`：RDKit 解析、连通性、电荷、完整分子式／质量校验，按官方互变异构体身份去重后统一排序。冻结总采样预算，例如每题 128 个序列分配给 5 个分子式；合法且不同的输出可能远少于 128，需如实计数。

第一项要分别报告预测分子式结果与“提供真实分子式”的研究上限，后者不能作为可部署成绩。第三项先复用指纹与化学软评分，随后再验证前向碎裂评分的仪器、加合物与碰撞能量适配。

**首个受控对照**：同一个冻结解码器、相同分子式候选和采样预算，分别输入监督指纹与 GAN 指纹。这样才能回答现有对抗学习是否改善了真实分子生成。当前推理将 8 个噪声指纹取均值；新实验可以比较均值条件与逐样本条件，但须在开发集预先选定，不能从验收答案反选。

## 备选：分子式条件图扩散解码器

DiffMS 由分子式固定重原子类型，学习生成包含单／双／三／芳香键的连接矩阵，比单次锚点改写的搜索空间更广。其结构预训练使用 radius=2 的 2048 位 Morgan；端到端模型实际使用谱图编码表征，因此相同指纹维数不保证检查点接口兼容。原模型隐式处理氢，生成结果仍可能氢数不符，必须增加完整分子式／质量验收。[原论文](https://arxiv.org/html/2502.09571v2)、[作者代码](https://github.com/coleygroup/DiffMS)

移植前检查元素词表、最大节点数、互变异构体和指纹设置是否覆盖本赛，特别是较大天然产物；按实际重原子数报告截断样本。先用小队列测离线依赖、显存及每题采样时间，再按 Kaggle 实际运行时限确定可完成的预训练、微调和采样预算，不能仅凭已有 GPU 判断可行。

## 是否必须继续使用 GAN

**真正生成分子需要解码器，不要求必须使用对抗训练。** MSNovelist 的序列学习与 DiffMS 的去噪交叉熵都提供了无 GAN 的可行范式。先验证监督解码器的真实结构召回，再把对抗损失作为单独消融。对抗判别器提高“像真实分子”的程度，未必提高“是该谱图对应分子”的程度；模式坍缩还可能减少前 25 名的不同候选。[MSNovelist](https://www.nature.com/articles/s41592-022-01486-3)、[DiffMS](https://arxiv.org/html/2502.09571v2)

后续若比较“解码器＋对抗损失”，应固定训练身份、初始化、生成器噪声、实际 G 更新数和采样预算，并记录额外 D 成本；同样的运行时间上限不保证同样的训练量。本轮先读取真实 GAN—监督结果，再决定保留哪种指纹条件，不预判收益。

## 如何验收真正的库外能力

- **冻结全库与预训练数据快照。** 验收真身份及全部原始别名同时从参考谱、候选结构库、解码器预训练中排除。随机身份留出和骨架／较远结构留出分别报告；仅事后分层不能称骨架隔离训练。MassSpecGym 提供区分生成、检索及严格结构泛化的参考协议。[原论文](https://arxiv.org/abs/2410.23326)
- **使用新的未观察验收集。** 本轮已查看的开发或验收队列不能复用来确认后续调整。预先选定分子式与采样预算，只在开发集调参，验收一次；保留 known 匹配保护的单独结果。
- **分别测三层上限。** 分子式 Top5 命中、真实指纹＋真实分子式的精确结构生成召回、实际谱图条件的最终 MRR@25。这样可以定位分子式错误、指纹错误或解码错误。
- **主指标是精确新召回和 MRR@25。** 同时报告新增真身份数、全局及逐题不同图数、合法率、质量通过率、重复率、耗时，按离子模式／加合物、质量和来源分层。Tanimoto 接近、分子有效或新颖率高，都不能替代精确身份命中。

把已知数据库分子人为移出所有库，只能证明模拟库外能力。真正 class 3 的效果需要官方类别和真值评估；未公开类别时不能从总体公榜反推该类准确率。

推进顺序：**读完本轮真实结果 → 独立分子式候选 → 共享 SMILES 解码器与重建上限 → 新库外验收 → 比较 GAN 条件或图扩散。** 本文是下一轮实施方案，尚未训练上述结构解码器，也没有据此产生新比赛成绩。
