这份清单规定如何读本轮结果，不预判 GAN 会提升。实际训练、Notebook 完成、比赛提交及公榜出分是四个分别核实的状态；成绩以 [运行状态](../kaggle_release_gan/status.json) 为准，历史背景见 [验收总报告](OVERNIGHT_RESULTS_20261002.md) 和 [泛化审查](GENERALIZATION_REVIEW_20261002.md)。

## 每个指标能支持什么结论

| 要回答的问题 | 主要证据 | 正确解释边界 |
|---|---|---|
| 对抗训练是否改善排序？ | `acceptance.cgan_vs_supervised_raw` 与 `cgan_vs_supervised_routed` 的配对差值和 95% CI | 两臂候选相同，收益来自学习/排名。差值区间下界 >0 支持本次验收分布中的优势；跨零表示证据不足，不能写“已确认提升” |
| 原始网络变好，部署为何没变？ | raw 与 routed 差值、`protected`、错误保护数及首位保留 | raw 改善但 routed 持平可能被保护/融合抑制；需分支统计支持。不能据此直接解除保护重跑同一验收 |
| 保护已知谱是否有代价？ | `known_acceptance` 的 MRR、Top1/5/25、GAN—监督与 GAN—历史差值 CI、样本数 | 已知子集与全未知集分母不同，应分别报告；CI 跨零或样本很少不能证明无损。空子集是无法验收，不是零准确率 |
| 是否真的增加正确结构候选？ | `original_mass_pool_recall`、`graph_only_newcoverage_molecules` 及具体新增真图病例 | 后者 >0 证明有限图编辑补到了原**本题可用池**缺失的真身份；不证明该结构从未在所有公共数据库出现 |
| 增加很多图为何仍不提升？ | 图生成数、`graph_output_count`、图新增正确覆盖、总体和候选内 MRR | 图数上升但新增正确覆盖为 0，说明扩大的是错误候选空间；可能挤后旧正确结构。合法与同分子式只是必要条件 |
| 更像训练结构还是能外推？ | `strata` 中 seen/unseen scaffold 与 acyclic 的样本数、召回及 MRR | 本轮是身份随机拆分后分层，**不是骨架隔离训练**；未见骨架分层不能独自证明严格新化学空间泛化 |
| 是否过拟合？ | 各轮 train-probe/dev BCE、gap、所选 epoch、验收排名相对开发排名 | 训练降而开发升是迹象；BCE 与 MRR 目标错配、来源差异也会造成不一致。probe 非全训练损失，单次 gap 不能断言主因 |
| 是否模式坍缩？ | `noise_probability_variance`、`noise_threshold_hamming_fraction` 的趋势及实际排名变化 | 噪声输出变得相同提示噪声被忽略；多样性高也不证明正确。推理平均 8 个指纹样本，没有逐样本分子图解码 |
| 公榜是否超过历史最佳？ | 新提交真实分数与 0.176 比较，保留时点和精度 | 这是**整套新版本**的外部结果，包含身份去重、保护阈值、模型及图编辑；不能把全部涨跌归因 GAN。三位小数相同只能称显示精度持平 |

MRR 衡量正确结构是否排在前面，0.176 不等于 Top1 17.6%。`candidate_recall` 是该臂排序前真身份可用率，Top25 是排序后命中率，两者不能互换。共享候选的 baseline/cGAN 召回应相同；若不同，应先核查统计范围或程序问题，而不是解释为 GAN 生成更多分子。

`supervised_vs_expanded_chemistry` 和 `cgan_vs_expanded_chemistry` 同时改变神经排名、路由及图编辑，**不是纯图编辑消融**。新增精确候选覆盖能定位生成机制是否有效；若要量化图编辑的独立 MRR 收益，下一轮需同一冻结排序器下有/无图编辑的专门对照。

## 生成能力的准确名称

本轮 GAN 生成 **2048 位指纹概率**；新分子图来自低置信查询的有限、确定性单键端点交换。图编辑保持锚点的元素数量、度数、键阶、分子式和精确质量，无法覆盖任意新骨架、任意官能团变换或任意未知分子式。模型没有已训练的图解码器。

判别器用于交替训练及向生成器提供对抗梯度，**本轮 release 排名不使用判别器候选分数**。候选的神经分数来自生成器预测指纹与规范化真实候选指纹的 soft Tanimoto，再按固定 RRF 和化学先验融合；探索 D 打分属于后续方案。

因此可以称“条件指纹 GAN 辅助排序，配合有限图编辑候选”。不能称“GAN 已直接生成全新分子图”。新颖性仅相对本题可用候选池，不是全 PubChem 新颖性或比赛真正库外类别已解决。`generated_molecular_graphs` 是各查询去重后数量跨开发/未知验收/已知验收/可见推理的总和；查看 `graph_generation_by_cohort`，不要当全局不重复分子总数。

## 明早验收时的结论规则

1. **优于监督对照且未知谱差值区间下界 >0**：报告本次协议下的局部对抗训练收益，并同时交代已知谱结果、实际更新量及单 seed 限制。
2. **点估计正、区间跨零**：报告可能收益及不确定性，不将其改写为确认提升。
3. **持平或下降**：保留真实负结果及失败病例，说明本组合未显示增益；不能由一次失败否定所有 GAN，也不能在已查看验收集上换参数再称独立验收。
4. **公榜提升但本地无 GAN 优势**：报告新版本公榜改善，GAN 独立贡献未证实；可能来自候选、身份去重或分布差异。
5. **本地改善但公榜下降**：优先分析场景/来源、候选覆盖及保护分支差异，保持已冻结参数；下一实验建立新协议和新未观察验收队列。

本轮用户要求的实验臂会提交获得外部反馈。提交并不等于科学验收通过；负结果后应整理诊断、预先登记下一轮假设，再开展新实验，不能反复使用此次验收或公榜挑选权重。
