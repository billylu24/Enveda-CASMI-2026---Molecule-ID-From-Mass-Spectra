# 成绩与泛化能力独立审查（2026-10-02）

当前真实公开成绩 **0.176**，与历史 hybrid 检索最佳持平。证据最充分的瓶颈是候选覆盖、候选竞争及验证分布；训练后期也出现了过拟合或训练目标与排名目标不一致的迹象。不能把所有下降都归因于神经网络过拟合，也不能把加入 GAN 当成已经解决库外新分子问题。

本报告根据已保存的实验记录、训练曲线、真实 Kaggle 输出及一次原始论文复核撰写。新的 GAN 执行及榜单快照由本轮运行报告另行记录；这里不预填尚未取得的成绩。

## 1. 如何理解分数和平均值

官方指标为每个分子的首次正确候选倒数排名的平均，前 25 名未命中则记 0；匹配依据 RDKit 2026.03.3 的互变异构体规范化及 InChIKey14，忽略立体化学。0.176 **不是 17.6% Top1 正确率**。例如，把正确结构从第 1 名降到第 2 名会损失 0.5 个单分子分值，新增一个第 25 名正确候选只增加 0.04。[比赛官方说明](https://www.kaggle.com/competitions/enveda-CASMI26-molecule-id-mass-spectra/overview)

已核实的 8 次提交：

| 方案 | 公榜 MRR@25 | 相对历史最佳 |
|---|---:|---:|
| 初始检索 | 0.140 | −0.036 |
| 共识检索 | 0.141 | −0.035 |
| hybrid + COCONUT | 0.176 | 0 |
| guarded MLP | 0.162 | −0.014 |
| 学习路由 | 0.169 | −0.007 |
| 60K 大模型 | 0.173 | −0.003 |
| PubChemLite 扩库 | 0.171 | −0.005 |
| ChEBI/LMSD + 化学先验 | 0.176 | 0 |

这 8 次成绩的算术平均为 **0.1635**，中位数 **0.1700**；最近 5 次为 **0.1702**。这些是我们提交历史的描述性均值，**不是独立复跑均值或全榜平均值**。不同方案、时间及选择行为相互关联，因此不能把这 8 次当成 8 个独立试验计算提升显著性。全榜平均、排名和头部差距必须使用实际同一时点榜单，不能根据这些历史记录猜测。

证据：[历史提交表](../results/kaggle_submissions.csv)、[最新提交状态](../kaggle_release_chemistry/status.json)。

## 2. 失误分成三个阶段

### 真结构在库外：排序再准确也无用

历史 2,000 分子开发审计中：1,816 个真结构不在生产候选数据库，18 个虽在库内但未通过质量窗口，只有 166 个进入候选池。固定候选池的完美排序总体 MRR 上限为 **0.083**，放宽所有质量筛选但不扩库也仅 **0.092**。这不是隐藏测试上限，是该开发队列的实际候选上限。

覆盖高度依赖来源：只来自 enveda-180 的 1,331 个开发分子，原库覆盖仅 1 个；GNPS 单一来源覆盖 58/192。随机分子留出不自动代表天然产物隐藏测试。库外结构无法从检索、指纹相似度或 GAN 判别器排名中产生；需要包含正确图的新候选机制。

证据：[直接排序与覆盖审计](DIRECT_RANK_20260929.md)、`artifacts/direct_rank_20260929/coverage_audit.json`、`coverage_by_source.csv`。

### 真结构入池后：新增竞争者把它挤后

PubChemLite 的独立未知谱集覆盖从 **8.25% → 12.00%**，增加 75 个命中。新增覆盖贡献总体 MRR **+0.004764**；原已覆盖的 165 个分子条件 MRR 从 **0.238749 → 0.212793**，贡献 **−0.002141**，抵消约 **45%** 的新增覆盖收益。总体 MRR 0.019697 → 0.022319，但配对差值 95% 区间跨零；公榜随后为 0.171，低于最佳。

因此，数据库条目更多不自动更好。优先把分子式、加合物、模式、诊断碎片、合理中性丢失及真实同分子式困难负样本用于限制候选竞争；不要单纯扩大质量窗口或用全库同权混排。

证据：[扩库报告](CANDIDATE_EXPANSION_20260929.md)、`artifacts/candidate_expansion_20260929/fresh_gain_decomposition.json`。

### 高置信度保护：可以保护正确匹配，也会保护错误首位

屏蔽查询同分子原始键后，最新 32 个旧 NP 行为例仍有 **23 个**超过 0.5 阈值；它们保留完整历史排名。该规则保护已知谱检索，但高数值相似度不是化学身份正确概率。相近结构、谱图碰撞或身份别名均可能产生高分。

32 例全部无 Top1 命中、Top25 命中 22 例。新增化学规则只在 9 个低置信例上提取，命中为 0；另外 23 例直接绕过该分支。因此不能从该运行说“所有 32 例均没有诊断碎片”，更不能从可见 400 例完全受保护推断隐藏集化学分支没有作用。

下一步应先测规则触发和正确官能团覆盖率，分离“有证据但规则没触发”“触发但候选未支持”“高置信保护绕过”等原因，然后在开发集校准错误高置信区间。规则缺失时通常不能作为结构排除证据。

证据：[最新聚合审计](../kaggle_release_chemistry/validation_summary.json)、`kaggle_release_chemistry/run_output/behavior_check.json`。

## 3. 可以复核的实际失误范例

下面均是此前已观察的 NP 行为诊断，**不是独立泛化验证，也不是隐藏测试错误解释**。榜单不提供逐分子标签，无法直接确定哪一隐藏题造成降分。

| 查询原始结构键 | 官方规范身份 / 置信度 | 扩库前 → 后 | 可确认的原因 |
|---|---|---|---|
| `BBNQQADTFFCFGB` | `CHERCCPWQNZOOH` / 0.215221 | 正确第 4 → 第 5；RR 0.25 → 0.20 | 新候选 `CXWYCAYNZXSHTF` 插入第 2，挤后正确结构；本题新增 4 个质量候选、3 个进入输出 |
| `CKLJMWTZIZZHCS` | 同原键 / 0.017486 | 正确第 5 → 第 6；RR 0.20 → 0.166667 | 新候选 `NSMPFGWDOGVQDR` 插入第 4；本题新增 1 个质量候选并进入输出 |
| `ACNHBCIZLNNLRS` | 同原键 / 0.603113 | 两版 Top25 都未命中 | 即便排除该原始同分子键，错误检索仍进入保护分支；没有新的规则或目录排序机会。现有审计不足以判定真结构本来缺库还是被排到 25 名之外 |

前两例相加即可解释这 32 例总体 MRR 从 **0.138849 → 0.136245**：`((0.20−0.25)+(1/6−1/5))/32 = −0.00260417`。Top25 没下降，不代表排名指标不下降；7 个名单变化仅 2 个使首次正确排名变化。

另一个实际身份问题：`BBNQQADTFFCFGB` 扩库前第 4 名与第 7 名 `CHERCCPWQNZOOH`，按官方规范是同一身份。按原始键去重仍可能让互变异构体占据多个 25 名槽位。`ALEXXDVDDISNDU` 的官方身份也变成 `XNMUPDICNYMLBM`，说明“raw inchikey14 不同”不足以证明结构不重叠。应对预测列表按官方身份稳定去重，仍保留首次出现的结构表示；同时审计排除参考时是否删除了所有官方等价别名。现有证据确认身份别名与重复槽位存在，**尚未确认这些别名在参考库中导致验证泄漏**。

## 4. 有多大可能是过拟合？

应区分四类问题：

| 假设 | 已有证据 | 目前能下的结论 |
|---|---|---|
| 神经网络训练后期过拟合 | 60K wide-enhanced 第 11 轮 loss 0.050381、开发 MRR 0.026092；第 16 轮 loss 降到 0.044763，但 MRR 降到 0.024689。旧 MLP 第 13 轮 MRR 0.015023、第 16 轮 0.014389，loss 继续下降 | 存在迹象；也可能由逐位 BCE 与候选排名目标错配引起。已用早停保留更早最佳权重，不能据此说部署用了最末轮坏权重 |
| 模型 / 融合选择过拟合开发集 | 图排序开发未知 MRR 约 0.020231，高于固定基线 0.017726；新独立集却为 0.016659，低于基线 0.017743，差值区间跨零 | 开发收益没有泛化。该冻结方案已拒绝，不应用同一留出再挑权重并称独立提升 |
| 谱图数量 / 仪器 / 来源捷径 | 学习路由去掉谱图数后，多数新方案损伤已知 Top1；单谱压力测试与原多谱代理差异明显。训练主要数据来源与天然产物目标来源覆盖差异很大 | 分布错配和抽样捷径有实证，需匹配谱条数与跨仪器测试。单纯减参数不能修复 |
| 公开榜反馈适配 | 多次依据同一公开榜反馈比较方案，隐藏真标签未知，私榜未知 | 存在选择偏差风险，但未测得公私榜差距，不能断言已经公榜过拟合 |

反证同样要保留：60K 大模型相对小模型在新独立 2,000 分子 unknown MRR 从 **0.015723 → 0.020205**，改善区间下限为正；known 从 0.791435 → 0.793328。扩大模型和数据在该协议下确有收益，后来公榜仍未超过检索，说明“神经网络无用”或“越大越过拟合”均不成立。

证据：`artifacts/scale_20260929/runs/wide_enhanced_60000/history.json`、`artifacts/experiment/runs/metadata_42/history.json`、[直接排序报告](DIRECT_RANK_20260929.md)、[规模报告](SCALE_20260929.md)、[路由消融](ROBUST_ROUTER_20260929.md)。

## 5. 新分子太少与外推不足是不同问题

当前历史 hybrid、MLP 指纹预测和新增化学先验均从已有结构目录挑选分子；没有可从指纹恢复唯一分子图的解码器。对真正不在全体候选库的图，这种设计没有准确命中机制。因此库外能力缺失是架构限制；但不能由未知类别比例未知的 0.176 公榜反推“库外题占多少”。

生成更多随机合法分子也不够：只有与查询相符的确切二维结构进入去重前 25 名才有分数。应报告原库缺失真结构的新增精确召回、去重后候选数、覆盖与条件 MRR；合法率、新颖率、最高 Tanimoto 仅为辅助。对同分子式位置异构体，较高相似度仍可能完全记 0。

随机分子拆分只能验证新身份，不保证新骨架外推。MassSpecGym 原论文进一步使用结构编辑距离拆分，指出微小结构变化可能让普通二维键拆分仍包含极相近的训练结构；本项目宜增加骨架不重叠及训练最近邻相似度分层。骨架分组是可执行近似，不能宣称与该论文 MCES 拆分等价。[MassSpecGym 原论文](https://arxiv.org/html/2410.23326v3)

## 6. GAN 实验应如何解释和验收

本轮最可执行的实验是 **条件指纹 GAN 与同容量监督指纹预测器**对照：谱图与模式 / 加合物 / 质量为条件，生成器加噪声产生指纹样本；判别器同时读取谱图条件与结构指纹。使用同样候选快照、训练分子、训练预算、保护门槛和融合规则，比较 G 的候选似然、D 的谱图—候选匹配分数及融合。只用无条件“像真实分子”的判别器不能保证解释查询谱图。

该实验如果最后按真实目录候选排名，检验的是 **对抗训练能否改善排序**。它不会突破库外结构召回上限，不能命名为“GAN 已生成新分子”。类似的 MS2MetGAN 在谱图条件下产生结构 latent 困难负例、最终用判别器排序候选；其测试数据库包含真结构，且谱图为正模式 [M+H]+，因此其成绩不能作为本项目库外能力证据。[MS2MetGAN 原论文](https://arxiv.org/html/2603.13342v1)

要检验真正新图能力，需要额外结构解码器并先测 **真实结构编码 → 解码的准确重建上限**。LatentGAN 本身依靠预训练 heteroencoder 解码，原论文测试合法率 98% 但正确重建约 80%；合法不等于正确，且原模型没有谱图条件。[LatentGAN 原论文](https://link.springer.com/article/10.1186/s13321-019-0397-9)

MolGAN 的原版小图实验最多 9 个重原子，作者报告模式坍缩；直接搬用原配置不能覆盖本赛的大分子。GAN 多次生成同图或等价形式会占掉有限候选预算，因此一定要计去重后多样性。[MolGAN 原论文](https://arxiv.org/html/1805.11973)

冻结实验必须满足以下条件：

1. **身份统一**：用官方版本互变异构体规范化身份建立拆分，训练、开发、留出及诊断队列相互排斥。保存 raw key → official key 映射，发现冲突就合并身份。
2. **拟合也排除**：未知谱评估真分子的全部谱图及别名从训练拟合与参考库删除；公开可见 400 例和此前 NP 诊断分子不进入新模型拟合。参考屏蔽不等于模型没见过。
3. **结构新颖性另报**：目录检索可以包含独立公共库的答案，不等于标签泄漏；若要声称未见结构生成，必须在结构预训练 / 解码器拟合中排除验收真图并报告库外真图子集。
4. **匹配比较条件**：A 为历史完整检索，B 为相同候选和同容量监督模型，C 为仅增加 GAN 损失；已知 / 未知场景用同一查询谱数及仪器条件。将自然候选覆盖、条件 MRR 和总体 MRR 分开，不把真标签硬插候选池作为正式主指标。
5. **开发选择后冻结**：checkpoint、生成样本数、融合权重及保护门槛只按开发集选择；冻结后新留出只打开一次。曾查看的历史队列及这 32 例只作描述性诊断。
6. **外推压力测试**：另报新骨架子集、训练最近邻相似度、质量段、天然产物来源、模式 / 加合物、跨仪器结果。不能将随机身份留出直接称新骨架泛化。
7. **报告真实失败**：若不提升，保留负结果和运行审计；Kaggle 是实验性外部反馈，提交成功与科学验收通过是两个状态。GAN 损失下降、判别器准确率或合法率都不能代替 MRR / 召回。

## 7. 改进优先级

**立即可执行**：官方身份去重与排除审计；同一查询集合的谱库 / 新库 / 化学规则 / 监督模型 / GAN 消融；把可见 smoke test 与真正留出分开；恢复、保存完整失败病例的候选覆盖、排名、质量和触发信息。

**下一轮建模**：增加真实同分子式困难负样本和列表排序损失；按仪器、模式、谱条数校准检索置信；避免错误高置信全名单保护；提高有实测覆盖的化学规则广度，并用公式与碎片解释筛选无关新候选。

**库外生成路线**：先建立条件结构解码和真 latent 重建对照，保留多个候选分子式；在相同生成与计算预算下比较有无 GAN，再评估精确新召回。若指纹 GAN 已跑通但库外召回仍为 0，这是实验的边界，并不是外推能力已经被检验或修复。
