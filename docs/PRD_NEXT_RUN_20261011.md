## 1. 决策摘要与背景

在 Enveda CASMI 2026 比赛中，团队近期取得了关键突破：队友 Canqiang 的 E006 版本成功刷新团队最高公榜成绩至 **0.440** (MRR@25)。随后，我们尝试在 0.438 的基础上引入“置信度自适应模拟器门控 (Adaptive Simulator Fusion)”，预期达到 0.44x~0.445，但实际在隐藏测试集上仅取得 **0.434**，且运行时间长达 **2 小时以上**。

本 PRD 的核心目标是：
1. **彻底复盘 0.434 未达预期的根因**，厘清算法偏差与工程瓶颈；
2. **明确肯定并全面吸收 0.440 的核心成功机制**，将其固化为不可动摇的基础底座；
3. **制定冲刺 0.448~0.452+ 的四大正交改进策略**，从加合物解耦、天然产物先验注入、确定性质谱门控与推理加速四个维度构建下一代流水线。

## 2. 真实复盘：0.434 未达预期根因剖析

### 2.1 算法机理失真：为什么启发式门控（Margin < 0.03）导致分数下滑？
在 0.44x 尝试中，我们设计了如下逻辑：若 GLACIER 的前两名打分差 $\text{Margin} < 0.03$，则认为 GLACIER“犹豫”，引入 20% 的 ICEBERG 进行混合重排。
经过离线日志审计与误差溯源，该机制存在三个致命缺陷：
1. **模拟器得分分布的“假胶着（Pseudo-ambiguity）”**：
   GLACIER 和 ICEBERG 输出的是预测质谱与实测谱图的余弦/熵相似度。对于大量结构极其相近的同分异构体，其理论碎裂谱差异极小，打分差天然处于 $0.01 \sim 0.02$ 区间。这导致 $\text{Margin} < 0.03$ 的触发率高达 **68.5%**，远超预想的“边界不确定样例”。
2. **软融合稀释了高精度峰特征**：
   GLACIER 基于 Transformer 结构，在 `[M+H]+` 上的碎片预测显著优于基于传统 GNN 的 ICEBERG。强行混入 20% 的 ICEBERG，实际上是对 GLACIER 引入了高方差的预测噪声，将原本排在第 1 名的正确结构降权到了第 2~4 名，直接造成 MRR 剧烈折损。
3. **脱离 0.440 基座的盲目叠加**：
   早期的 0.44x 运行是在 0.438 (Window=80, 原始 SMILES 融合) 的底座上实施的，完全缺失了 0.440 最核心的 **Metric-Identity 去重** 与 **Window=40 严格约束**。在 80 个长尾噪声候选的池子中加入模拟器微调，反而放大了长尾伪阳性。

### 2.2 运行时瓶颈复盘：为什么运行会长达 2 小时以上？
很多队员对“为什么 Notebook 在提交后跑了 2 个多小时”感到困惑。原因完全在于以下工程开销的累乘：
1. **全量 400 分子执行 vs 12 分子 Smoke Check**：
   公开 Notebook 在可见测试集上仅执行 12 个分子的快速 smoke 测试（数分钟即可完成）；但在提交到 Kaggle 后，环境自动切换至 `IS_RERUN = True`，处理全部 400 个隐藏测试分子。
2. **双引擎与双模拟器的四重串行开销**：
   - 主流程包含：Engine 1 (v1/v4g 检索 + PubChem 扩展) -> Engine 2 (BIO + AFIX 两段式排序) -> ICEBERG 模拟器预测 -> GLACIER 模拟器预测。
   - 每个测试分子需要对 40~80 个候选逐个进行 RDKit 分子图构建、碎片树展开、深度模型前向推理。
3. **进程间频繁的低效磁盘 I/O**：
   为了防止 PyTorch CUDA 上下文在父子进程中冲突，Engine 2、GLACIER 和 ICEBERG 分别以 Python 子进程运行，中间数据通过磁盘巨型 JSON/NPY 文件交互（如 `eng_lists.json`、`gl_out.json`）。文件序列化、反序列化以及跨进程上下文初始化的时间累计超过了 40 分钟。

## 3. 必须借鉴 0.440 的核心机制（底层架构固化）

**结论：必须 100% 借鉴并继承 0.440 的核心设计！0.440 是目前团队无可争议的最优架构基石。**

0.440 (Canqiang E006) 之所以能够从 0.438 跃升至 0.440，根本原因不在于复杂的超参数调整，而在于以下两大极其深刻的“化学信息学与评测准则对齐”：

### 3.1 结构级“一物一票”去重融合（Metric-Identity Fusion）
- **旧方案缺陷**：以 SMILES 字符串作为键进行 RRF 融合。同一个分子的不同互变异构体（Tautomers）或质子化异构体被视为不同候选。如果某个骨架在库中有 5 个异构体，它在 RRF 中就会被累计投票 5 次，产生严重的**重复刷票偏差（Duplicate-Vote Bias）**，把真正独特的新骨架挤出 Top 25。
- **0.440 机制**：严格按照官方评测函数 `canonicalize_smiles_to_ik14`，在 RRF 融合前对所有候选提取剥离立体化学后的互变异构体规范化 InChIKey-14。在各引擎内部，**每个拓扑母核仅保留最佳排名的那一票**：
  $$\text{Score}(K) = \sum_{e \in \{\text{eng}_1, \text{eng}_2\}} \frac{w_e}{3 + \text{first\_rank}_e(K)}$$
- **价值**：彻底根除同义刷票，保护骨架多样性，使 Top 25 槽位的有效信息量达到最大。

### 3.2 融合候选池窗口紧缩（Window 80 -> 40）
- 0.438 将候选池深度设为 80，试图提高候选召回（Recall）。
- 但实测发现：质谱模拟器在区分结构时，其辨识能力仅在近邻范围内有效。排在 40~80 名的候选往往存在较多低质、罕见的非天然结构。模拟器偶发的碎片匹配虚高，很容易把这些尾部噪声候选提权至 Top 25，直接拉低 MRR。
- **0.440 断然将候选池收窄至 40**，建立了强大的“抗噪屏障”。

### 3.3 无缝 ICE Fallback 兜底
- GLACIER 仅支持 `[M+H]+` 正离子加合物；对于负离子 `[M-H]-` 及其他特殊加合物，GLACIER 无法运行。0.440 保持 `ice_fallback = True`，在 GLACIER 盲区完全由 ICEBERG 保底，兼顾了特异性与全覆盖。

## 4. 下一阶段（0.450+）四大正交改进支柱

在将 0.440 的“Metric-Identity + Window 40 + ICE Fallback”作为冻结基石的前提下，下一代版本必须探索**正交且不冲突的新增量**：

```
                    ┌────────────────────────────────────────────────────────┐
                    │               0.440 冻结基座 (Invariant)                │
                    │   Metric-Identity Fusion + Window=40 + ICE Fallback    │
                    └────────────────────────────────────────────────────────┘
                                                 │
         ┌───────────────────────┬───────────────┴───────────────┬───────────────────────┐
         ▼                       ▼                               ▼                       ▼
【支柱 1：加合物解耦】    【支柱 2：天然产物先验】        【支柱 3：确定性质谱门控】    【支柱 4：工程剪枝加速】
- [M-H]- 负离子专属通道   - COCONUT 2.0 / LOTUS 骨架注入   - 中性丢失 (Neutral Loss) 规则 - Top-1 显著性早停
- 钠/铵加合物特征适配     - 暗化学空间天然产物加权         - 特征碎片离子硬匹配惩罚/奖励  - 跨进程零拷贝与批推理
- 极性特异性 RRF 权重     - PubChem 结构度先验校准         - 替代失效的浮点 Margin 启发式 - 运行时间压降至 ≤45min
```

### 支柱 1：加合物与电离极性解耦排序（Adduct & Polarity Disentangled Ranking）
- **现状**：当前流水线将正离子（Positive）与负离子（Negative）混用相同的 RRF 权重和相似度计算。
- **改进**：
  1. 统计显示，测试集中约有 20%~25% 的分子属于负离子模式（`[M-H]-`）或非单质子加合物（`[M+Na]+`, `[M+NH4]+`）。
  2. 针对 `[M-H]-`，禁用无法预测负离子的 GLACIER，提升基于负离子指纹模型的检索权重（$w_{\text{neg\_fp}}$）；
  3. 针对 `[M+Na]+`，因为钠加合物极难产生有效碎片（多为母离子孤峰），强制大幅提高同前体质量下的 PubChem Popularity 先验权重，减少对虚假碎片的过度拟合。

### 支柱 2：高质量天然产物（NP）专属先验注入
- **背景**：Enveda 作为天然产物发现公司，其竞赛核心即为“从复杂生物提取物中解析暗化学空间天然产物”。
- **改进**：
  1. 在 Engine 2 候选库中，除了已有的 COCONUT，系统性对齐 LOTUS（天然产物分类数据库）与 NPAtlas 的骨架信息；
  2. 引入 `NP-likeness Score`（天然产物相似度评分）。对于排名前 40 的候选，将其天然产物评分与检索得分做线性融合，优先将符合次生代谢产物特征的候选推入 Top 25。

### 3.3 支柱 3：基于确定性质谱特征的精确门控（Deterministic Spectral Gating）
- **抛弃**：彻底废弃基于浮点打分差（$\text{Margin} < 0.03$）的模糊启发式分支。
- **引入**：基于确定性物理/化学碎裂规则的加分与降权：
  1. **特征中性丢失（Neutral Loss Matching）**：
     - 若实测谱图中存在 $18.0106$ ($\text{H}_2\text{O}$) 的强中性丢失，而候选分子结构中无羟基（$-\text{OH}$）或羧基（$-\text{COOH}$），直接施加 $-0.5$ 惩罚；
     - 若存在 $176.032$ (葡萄糖醛酸苷脱落) 或 $162.053$ (己糖脱落)，候选分子必须具有匹配的糖苷配基骨架；
  2. 只有在确定性化学证据支持时，才在同分异构体中调换顺序，确保每一次重排都有可靠物理证据。

### 3.4 支柱 4：推理性能与运行开销工程化重构（Runtime & Latency Optimization）
- **目标**：在 400 分子全量隐藏测试上，将总执行时间从 **>120 分钟** 压缩到 **≤40 分钟**。
- **措施**：
  1. **显著性置信度早停（Significance Early-Exit）**：
     若检索阶段 Top 1 分数与 Top 2 分数之比超过 $1.8$ 且包含高强度匹配谱图（检索置信度极高），直接锁定 Top 1，跳过昂贵的模拟器重新打分；
  2. **内存常驻与 Numba AOT 预编译**：
     消灭跨脚本的磁盘 JSON 反序列化，将共享特征矩阵与模型常驻，复用预编译的 Numba 缓存。
