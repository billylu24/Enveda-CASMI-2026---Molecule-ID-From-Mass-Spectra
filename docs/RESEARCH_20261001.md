# 化学证据与谱图结构生成实验

本轮实现精确化学证据重排序、DINO 谱图预训练和受约束 SMILES 生成。它们是有独立对照和冻结协议的实验模块；实现完成不代表比赛成绩提高。历史最佳公开分数仍为 0.176，现有生产配方不会因新模型训练完成而自动替换。

## 化学证据

`casmi_ml.chemistry` 保留 float64 峰质量，识别诊断离子、前体与碎片差值、峰间差值和连续丢失。规则带有文献来源、模式、加合物与 SMARTS 支持条件。水、氨、一氧化碳、二氧化碳和糖基丢失提供软支持；磷酸胆碱峰提供类别支持。SMARTS 是保守启发式，不是排他性碎裂定律。未观察到相应峰不扣分。

仅对明确适用的单电荷单体离子及高分辨率仪器启用精确规则。未知仪器、二聚体、多电荷和不确定的金属加合形式仍保留原始观测，不猜测碎片电荷。离子解析器支持分子倍数、正负电荷、原子增减与电子质量修正。原始检索的候选窗口在首轮保持不变，以单独测量证据评分的作用。

高分辨率单峰容差为 `max(10 ppm, 0.002 Da)`；差值使用两个测量端点容差之和。证据跨谱取最大支持，避免重复谱条数增加票数。仅重排基础排名前 100 个结构，记录真实答案进入短名单的比例；相同证据分数使用同一证据名次，无信息时保持原排序。

MetFrag 2.6.11 使用本地 CSV 候选、2 层碎裂、10 ppm/0.002 Da 碎片匹配、单任务 60 秒超时和 1 GiB Java 堆。仅对高分辨率 `[M+H]+`、`[M-H]-` 启用。缓存包含工具 SHA256、输入峰、离子信息与完整候选结构；超时和失败不会缓存为永久否定。没有模拟碎裂结果时不淘汰候选。当前方法比较质量解释及碎裂评分，不预测完整的碰撞能相关强度分布。

## 数据隔离和验收

新开发集 2,000 分子、留出集 4,000 分子，排除以前准备过的训练、开发、诊断和留出队列。开发来自原始 dev 拆分，留出来自原始 holdout 拆分。查询每分子最多 9 条谱，按可见测试的条数分布抽样，并受实际可用谱数限制。已知和未知参考场景使用同一组查询；已知场景删除查询及同分子的完全相同副本。

队列、规则、模型与配置使用 SHA256/冻结 JSON。所有候选表示来自训练库或公共目录，不把评估答案加入候选。历史 hybrid 与冻结 60K 配方在同一队列比较。开发检查未知 MRR 改善、已知 MRR 下降不超过 0.001、已知 Top-1 下降不超过 0.005。通过后才打开留出集，使用按分子的配对 bootstrap；未知差值 95% 区间下限必须大于零。已知保护门槛为点估计规则，不等于统计非劣证明。

为防止多阶段依次窥视留出标签，完整工作流在所有开发选择后写入 `joint_selection.json`，再进行独立验收。单独执行 `accept` 时，操作者也应先完成其他开发选择。旧实验队列仅用于排除与历史审计。

## DINO 与生成

谱图模型为 4 层、256 维、128 峰 Transformer，诊断峰在允许预算内优先保留，元数据使用历史训练拟合的预处理。监督、遮蔽峰和 DINO 三个对照使用相同 60K 训练分子，每轮每分子抽一条谱。遮蔽峰同时隐藏质量、丢失及 Fourier 通道，避免目标泄漏。

DINO 使用学生与 EMA 教师、1024 个投影输出、教师温度 0.04、学生温度 0.1、中心动量 0.9。增强仅弱峰丢弃和轻微强度扰动，保留识别到的诊断峰，不移动峰质量。先预训练最多 20 轮，再指纹微调最多 30 轮。表征均值标准差和有效秩检查用于发现坍塌；实际候选排序才决定是否值得继续。教师参数无梯度，教师始终处于 eval 模式。DreaMS 的预训练数据重叠尚未审计，因此当前没有把外部权重结果列为独立收益证据。

生成器为 6 层、256 维自回归 SMILES Transformer，条件为冻结 60K embedding、训练拟合元数据及预测元素计数。元素计数分类器产生前 5 个分子式假设，解码器始终使用预测的软元素计数；真实分子式只用于训练元素预测目标和单独的 `--oracle-formula` 理想条件诊断。

最多生成 128 个、最长 256 token 的序列。输出需终止、可经 RDKit 解析、为单个连通分子并符合观测中性质量窗口；规范化和二维结构去重后，用生成概率、化学证据、预测分子式支持和可选 MetFrag 排序。分子式预测不作硬过滤。提交合并保留高置信检索分支，低置信候选采用预先固定的 RRF 权重。报告纯生成与合并检索的指标、有效率、质量匹配率、库外精确命中及失败原因。

初次生成评估默认 100 个开发分子、每个 128 次采样；它是两周首轮可行性检查，不等同于完整 4,000 分子独立验收。不得把 token NLL 或分子式准确率作为结构识别提高的证明。

## 运行方式

项目已存在 CPU/GPU 虚拟环境，Java 可用。下载 MetFrag 并保存其来源和 SHA256 后，可运行：

```bash
.venv/bin/python -m casmi_ml.chemistry_experiment prepare
.venv/bin/python -m casmi_ml.chemistry_experiment develop --metfrag-jar external/metfrag/MetFragCommandLine-2.6.11.jar
.venv-gpu/bin/python -m casmi_ml.representation_experiment supervised
.venv-gpu/bin/python -m casmi_ml.representation_experiment masked
.venv-gpu/bin/python -m casmi_ml.representation_experiment dino
.venv-gpu/bin/python -m casmi_ml.generation_experiment train
```

从已完成结果继续完整工作流，使用：

```bash
.venv-gpu/bin/python -m casmi_ml.research_runner --metfrag-jar external/metfrag/MetFragCommandLine-2.6.11.jar
```

三个阶段分别最多 24 GPU 小时；表征阶段的监督、遮蔽、DINO 及种子复跑共享同一预算，生成阶段另计。预算台账跨运行持久化；数据准备与 CPU MetFrag 耗时另记。完整工作流顺序执行训练，避免多训练进程争用同一单卡。默认种子 42，仅开发赢家追加 43、44，不按留出集选择种子。

化学验收通过后，`casmi_ml.research_release` 可准备带权重、配方和证据的本地发布目录。`secondary_inference --recipe ...` 接受新的 `chemistry` 可选配置；与其他实验扩展组合须另行验证，当前禁止自动组合。格式仍为每分子最多 25 个二维结构。工作流没有上传或比赛提交操作。

## GAN 可行性结论

MolGAN 官方数据准备示例限制在不超过 9 个原子的小分子；当前 60K 集抽样重原子数中位数 23、95 分位约 41。直接移植该示例会排除绝大多数训练结构，而且不能处理谱图条件识别这一目标。

后续 GAN 对照应从本轮生成器初始化，引入接收“谱图表征＋分子结构”的条件判别器，同时区分真实匹配、相同质量错误匹配和生成结构。先保持监督序列损失，再以离散序列的策略梯度加入条件匹配奖励；MetFrag 只作不可微奖励或后处理。与同样采样预算的自回归模型比较精确 Top-25、有效率、唯一率及库外命中，按重原子数分层。若只改善分子合法性而不能改善谱图条件识别，则不推进。GAN 训练不属于本轮优先项。

## 已发现的问题与协议修订

2026-10-01 的首次开发运行发现：将部署保护资格同时作为早停信号，会在所有早期 checkpoint 都不合格时过早停止学习。正式表征对照改用纯神经开发 MRR 判断收敛，再独立筛选部署资格；微调 RNG 使用单独种子，DINO 增强只丢弃弱峰并保留强峰和诊断峰。修订在读取任何留出指标之前完成，正式运行保存为 `*_42_v2`。旧运行仅保留作开发诊断，不参与最终模型比较。遮蔽峰预训练未改变，可复用已完成权重；DINO 增强改变，因此重新预训练。

开发集化学消融选择了 MetFrag 权重 0.5：未知谱 MRR 0.018412 → 0.021366，已知谱 MRR 0.590293 → 0.591915。纯启发式丢失评分没有带来开发收益，诊断离子评分没有改变该队列的总体指标。此处不是独立验收，也不能推断榜单收益。留出化学评估重新调用实际 CPU float32 逐组神经推理，防止批量数值误差引起近同分候选换序。

新开发审计的未知场景：169 个分子已进入候选池、1,810 个目录缺失、21 个存在于目录但未进入窗口，候选召回上限 8.45%。通用加合物解析支持全部新查询组中的至少一条谱，但首轮生产检索仍保留历史质量换算。因此下一轮质量换算实验应独立比较单体、二聚体、多电荷和金属加合物，不能把现有重排序收益归因于这些尚未启用的修正。

质量覆盖对照也已运行：在同一个生产候选目录中，旧换算召回 168/2,000，通用加合物换算的中位数方案召回 177/2,000，各谱质量假设并集召回 183/2,000。中位候选数从 157.5 增至约 250，说明新增覆盖也带来更多竞争。这是覆盖实验，没有修改当前排序或部署配方；其目录不包含历史混合列表的额外质量表示，因此不能直接与上述 169 个联合候选命中混为同一统计口径。

正式表征对照已完成：监督 Transformer 最佳合格未知 MRR 0.018406，遮蔽峰 0.018258，DINO 0.017537，均未超过冻结 60K 基线 0.018412。因此本轮没有表征赢家，也没有打开表征留出验收。这只评价当前数据、增强、容量和指纹任务配置，不否定 DINO 在更大规模或其他任务上的用途。

25 个真实低置信度开发查询已按实际 MetFrag 接口重新计算，完整候选排序全部与冻结化学评分一致。该检查验证实现一致性，不作为新的统计收益证据。


生成首轮训练于第 26 轮早停，最佳开发 token NLL 约 0.5803。100 分子开发试验的 12,800 次采样中，90.05% 可解析，0.74% 满足质量约束，分子式 Top-5 命中 4%。纯生成 MRR 0.017500；合并检索 MRR 0.004574 → 0.005343，新增 2 个候选池外精确答案，配对差值区间为 [0, 0.002308]。100 分子留出可行性检查的合并 MRR 均为 0.011187；新增 3 个池外精确答案，但未进入合并后的有效前 25 名。该试验不是完整独立验收，不给生成模型部署资格。

2026-10-02 修正了生成报告中已知场景临时变量覆盖未知场景配对明细的问题。结构排名和各场景 MRR 未改变；配对统计已按同一场景重新计算，并加入回归测试。JSON 写入改用独立临时文件，化学预测按场景持有排他锁；每进程最多 4 个独立分子任务，顺序收集，重启复用已完成记录与内容缓存。以上执行修复没有改变冻结规则、模型或开发选择。

下一轮优先处理：扩大可信候选目录；把通用加合物质量覆盖改进作为独立排序实验；提升分子式预测与解码中的质量约束；重新开发生成候选的合并策略。DINO 需要新的任务或数据规模证据后再扩展，GAN 暂保持后续设计项。


无标签生成接口已对全部 400 个可见测试分子运行，约 4.8 秒、峰值进程 RSS 562 MiB。全部查询受高置信分支保护，完整排名与冻结检索 CSV 相同，未读取查询分子式。此检查覆盖真实模型加载、保护回退和格式，未覆盖真实测试上的低置信生成路径；该路径另有开发采样与隔离单元测试。
