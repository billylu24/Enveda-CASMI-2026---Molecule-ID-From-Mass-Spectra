# 持续研究循环

用户已授权持续诊断、实验、评估、达到开发门槛后提交 Kaggle、每个完整轮次同步 GitHub，直到用户明确停止。配置在 `configs/research_loop.json`，持久状态在 `artifacts/research_loop/state.json`。

```bash
.venv/bin/python -m casmi_ml.research_loop status
.venv/bin/python -m casmi_ml.research_loop run
.venv/bin/python -m casmi_ml.research_loop stop
.venv/bin/python -m casmi_ml.research_loop resume
```

停止命令写入 STOP 文件；活动子进程组会终止，未完成实验可恢复。GPU 表征和生成训练分别限制每轮 24 小时，启动时持久预留额度，正常结束退回未使用额度；硬终止保留全额预留。共享 GPU 锁保证跨阶段单卡顺序执行。

完整开发门槛为未知分子至少 2,000，MRR@25 绝对增益至少 0.0005 且相对增益至少 2%，已知 MRR 下降不超过 0.001、Top-1 下降不超过 0.005。候选扩展实验必须实际排名评估，覆盖率提升本身不允许提交。配对 CSV 的分子键必须完全相同，并与汇总报告相符。历史化学独立验收的严格发布入口仍保留；新增开发版本使用 `experimental_release` 明确标注实验、无独立验收。

`evaluate_round` 与当前开发最佳进行同队列比较，并报告固定五折分子分组结果。分组是描述性开发诊断，不是折内重新训练的交叉验证；重复使用不能视为新独立证据。开发最佳和公共榜单最佳分别保存。公共回退不覆盖 0.176 的历史最佳。
